# 실행 결과

`Experiment.save()`는 `Global/artifacts/이름/실험명/실행ID/`에 새 결과를 만들며 이전 실행을 덮어쓰지 않는다.

| 파일 | 내용 |
|---|---|
| `result.json` | 저장 시각·검증 점수·모델 설정·데이터와 코드 식별 정보·환경. `poc exec` 실행 파일·인자와 원래 설정 파일명도 기록 |
| `predictions.csv` | 검증 환자의 ID·정답·예측 확률 |
| `models/` | 개인 코드가 내보낸 모델 파일 |
| `config.toml` | 실행에 사용한 설정 |
| `source/` | 실행 시점 개인 실험 폴더의 Python 코드 사본. `.venv/`·캐시 제외 |
| `resources/` | 추가 학습 설정과 실제 사용한 환경의 패키지 목록·고정 버전·기준 환경 정보 사본 |
| `shared_source/` | 실행 시점 공통 Python 코드 사본 |

모델은 개인 코드에서 내보내고 `save()`에 파일을 전달한다. 공통 기능은 원래 형식을 유지해 복사하며 모델을 실행하거나 변환하지 않는다. [저장 API](../docs/parallel-work.md#4-학습하고-결과-확인하기)

내보낸 모델과 생성 파일은 **개인 실험의 `outputs/`** 또는 임시 폴더에 둔다. 예를 들어 `Members/이름/experiments/exp001/outputs/model.json`이다. `outputs/` 전체와 `models/` 아래 JSON 모델은 Git에서 제외하고 강제 추가도 검사에서 차단한다. JSON의 내용만으로 모델과 설정을 자동 구분하지 않으므로, 모델은 설정 폴더나 실험 폴더 바로 아래에 두지 않는다.

추가 학습 설정은 `configs/`에 두고 코드와 함께 커밋한다. `models/network.py` 같은 Python 모델 정의도 커밋할 수 있다. `save(model_files=...)`로 전달한 출력은 위 결과 폴더의 `models/`에 복사하며, 추가 설정과 중복 보관하지 않는다.

| 기타 경로 | 내용 |
|---|---|
| `Global/artifacts/comparisons/` | 자동 비교표 |
| `Global/artifacts/smoke/` | 실행 점검 결과 |
| `Global/artifacts/.remote/` | 원격 비교용 점수·예측·검증 정보. 모델은 내려받지 않음 |
| `Global/artifacts/.restored/` | `restore --run-id`로 검증하여 내려받은 전체 재현 파일 캐시 |
| `Global/artifacts/final/평가명/` | 확정 계획·선택한 실행 사본·테스트 예측·최종 집계 보고서 |

비교할 때 지정하는 경로는 실험 폴더가 아닌 **`result.json`이 있는 실행 ID 폴더**다. [비교 방법](../docs/parallel-work.md#5-두-가지-비교를-구분하기)

## 추가 설정 보관

개인 실험 폴더와 하위 폴더의 **UTF-8 텍스트 설정**을 `resources/`에 같은 상대 경로로 보관한다.

| 대상 | 예시 |
|---|---|
| `.toml`, `.yaml`, `.yml`, `.json`, `.ini`, `.cfg` | `configs/model.yaml`, `preprocessing.json` |
| 패키지 파일 | `requirements.in`, `requirements.txt`, `requirements.lock` |
| 기준 환경 정보 | `environment.json` |

공통 환경으로 실행한 경우 Python·설치 패키지 버전은 `result.json`에 기록한다. 개인 환경 파일이 있으면 이름별 또는 분리한 실험 폴더에서 `resources/requirements.in`·`resources/requirements.lock`·`resources/environment.json`으로 복사한다. 이후 패키지를 변경해도 이미 저장된 실행의 사본은 바뀌지 않는다.

실제로 사용한 공통 설정은 실행 폴더의 `config.toml`에 따로 저장하므로 `resources/`에 중복 저장하지 않는다. 추가 설정은 **파일당 1MiB, 합계 8MiB·256개**까지다. 용량 초과·지원하지 않는 내용은 설정을 확인하고 정리한 뒤 다시 학습한다.

숨김 경로·`.venv/`·캐시·데이터·모델·생성 결과용 폴더는 추가 설정 수집에서 제외한다. 예를 들어 `configs/model.yaml`은 보관하지만 `data/patients.json`은 보관하지 않는다. Python 보조 코드는 별도로 `source/`에 모으므로 `models/network.py`처럼 모델 정의를 나눠도 된다.

추가 설정 파일에는 학습 설정만 둔다. 토큰·비밀번호·환자 데이터는 넣지 않는다. 폴더 밖 파일과 자동 보관 대상이 아닌 자료가 필요하면 별도 위치·버전·준비 방법을 기록한다. 설정 사본을 보관하는 기능이 외부 파일까지 자동 복원하지는 않는다.

학습 시작 후 코드·설정·패키지 고정 파일을 바꾸면 저장을 중단한다. 수정하려면 해당 학습을 마친 뒤 새 실행으로 기록한다. 저장된 `result.json`에는 추가 설정의 파일별 크기·내용 식별 정보가 포함된다.

## 서버 공유와 재사용

MLflow 연결 시 전송 범위는 다음과 같다. 원본·준비 데이터는 전송하지 않으며 기록된 버전의 공통 준비 명령으로 다시 만든다.

| 전송 시점 | 서버 파일 |
|---|---|
| 저장 후 백그라운드 자동 전송 | `bundle/`의 `result.json`·`predictions.csv`·`config.toml`·파일 검증 정보와 조회용 점수·설정 |
| `./dev archive`로 선택 | 같은 실행의 `reproduction/`에 모델·코드·추가 설정·패키지 고정 파일·기본 결과 파일 전체와 검증 정보 |

환경·패키지·데이터 버전·코드 식별 정보는 자동 전송되는 `result.json`에 포함된다. 모델·코드·추가 설정·패키지 고정 파일 사본은 [추가 전송 완료](../docs/tracking.md#선택한-실행의-모델-보관) 후 [`./dev restore`](../docs/tracking.md#보관한-실험-복원)로 새 개인 실험에 복원할 수 있다. 파일의 크기·내용 식별 정보를 검사하고 기존 실험은 덮어쓰지 않는다.

`save()`는 로컬 저장만 수행하며 서버를 기다리지 않는다. 완료된 `result.json`이 있는 실행을 Docker 작업 환경의 전송기가 기본 60초 간격으로 찾는다. 환경을 꺼도 결과는 남으며 다음 시작 때 미전송 결과를 처리한다. 자동 전송 대상은 기본 `Global/artifacts/`이며, 다른 경로 또는 작업 환경 밖에서 저장한 실행은 `./dev sync --root "결과 경로"`로 전송한다.

- 실행 폴더는 직접 수정하지 않는다. 비교에는 점수·예측이, 모델 재사용에는 모델·코드·환경 정보가 함께 필요하다.
- 모델 보관 완료 전에는 로컬 실행 폴더를 지우지 않는다. 기본 결과만 전송한 모델은 로컬에만 남으며, 로컬·서버 파일은 자동 삭제하지 않는다.
- 모델 읽기 코드·추가 파일·패키지·장비 조건은 실험 작성자가 기록한다. 코드 사본만으로 모든 환경이 복원되지는 않으며, 출처를 확인한 모델만 불러온다.
- 이 폴더는 Git에서 제외한다. 검토한 집계표·그래프만 [`Global/reports/`](../reports/README.md)로 복사한다. 모델·환자별 예측·ID·파형·코드 사본은 복사하지 않는다.

최종 평가의 `final/평가명/report/`에는 집계표·그래프만 생성한다. 상위 `runs/`에는 모델·검증 예측, `predictions/`에는 환자별 테스트 예측이 있으므로 평가 폴더 전체를 Git에 복사하지 않는다. 최종 평가 파일은 일반 학습 결과처럼 MLflow에 자동 전송하지 않는다. [최종 평가 파일](../docs/final-evaluation.md#4-보고서-생성)

현재 결과 형식은 `schema_version = 3`이다. 같은 형식의 이전 결과에 저장 시각이나 학습·평가 코드 구분 정보가 없어도 읽을 수 있다. 구분 정보가 없는 결과의 입력 그룹 비교에는 전체 공통 코드 일치를 요구한다. 다른 결과 형식은 동일한 준비 데이터와 현재 개인 학습 코드로 다시 실행해야 한다.
