# Raw ECG cohort supplied for the DL rebuild

`final_split_v2_augmented.csv` is the patient-level source of `pid`, `split`, and binary `SCD` labels. IDs are read as strings. The file contains 590 unique patients: train 407 (123 positive, 284 negative), validation 81 (10 positive, 71 negative), and test 102 (13 positive, 89 negative). The target event horizon and censoring definition are not recorded in this CSV.

The current `wave/{pid}.npy` files are memory-mappable float16 arrays with observed shape `(sample, 3)`, not the `(window, lead, sample)` format used by the existing shared Holter pipeline. Eleven files match a split PID: 9 train (4 positive, 5 negative), 1 validation (positive), and 1 test (negative). One additional file, `P0016-2.npy`, has no split row. The rest of the cohort files are currently missing. Each matched array has three numeric columns; this directory has no metadata naming the leads or confirming their order. The validation cohort currently has one class and one patient, so it cannot support useful checkpoint selection or early stopping; the test cohort is also one patient and single-class.

The arrays do not contain a sampling-rate field, timestamps, quality mask, noise marker, or segment metadata. The local MUSIC recording documentation describes 200 Hz, which is configured as the raw pipeline's source-level rate; it is not embedded in these NPYs and must be checked against their provenance before interpreting segment duration. Column names/order remain unknown. Raw training requires `source_metadata_confirmed: true` only after the sample rate and sample/lead axes are verified against source provenance. Do not infer noise from zero-valued samples or reuse `sqi_pass` from the separate `datas/Holter/windows` source. The raw training pipeline also requires a complete 30-second quality index and is intentionally gated until upstream metadata is available. The legacy trainer remains independently available for the SQI-window source.

The raw cohort inventory and exclusion report are produced in `DL/model_experiment_only_DL.ipynb` through `dataloader.segmented_ecg.inspect_raw_cohort()`. `DL/dataloader/raw_waveform.py` consumes `{pid}.npy` files as memory-mapped sample-major arrays, segments at the configured rate, and preserves original segment indices. Training is intentionally gated until an aligned quality index is supplied. The expected CSV columns are `pid,window_index,usable`, one row per complete 30-second segment, with a zero-based original segment index and an explicit 0/1 usable flag. This prevents assigning arbitrary labels or treating unknown-quality intervals as valid.

The shared per-lead CNN does not assign names to columns or assume a two-lead file corresponds to the first two leads of a three-lead file. It encodes every measured lead with the same weights, then averages only measured-lead features for each segment. Lead padding is performed only by the batch collator, independently of time padding. Lead identities remain unavailable in raw files; the unrelated legacy index names X/Y/Z and cannot establish their correspondence.
